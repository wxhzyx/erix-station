# 控制台组件改版与运行端口

2026-11-03，版本 0.1.48。

- Element Plus 2.14.7 / icons-vue 2.3.2 exact pin。统一导航、按钮、弹窗；成员、交付、配额和监听表使用组件表格。个人设置使用 Card / Descriptions，交付表单使用 Form / Select / Upload。
- 管理导航横向排布，成员列表隐藏内部 FDE 名和冗余 MFA 列；原安全设置留在编辑弹窗。
- 开发交付包支持拖入与选择文件，原上传/下发/删除 API 和权限保持不变。模型 API 仍由管理员配置。
- 运行端口改为真实观察，域账号 / SSO 姓名、项目、端口、状态、路由分配。分配号池查询留在成员端口搬迁表单中。
- 弹窗使用 Element Plus 焦点约束，保留首次输入聚焦、Esc/遮罩关闭请求、父组件 busy 拒绝关闭、原滚动状态及触发按钮焦点恢复。
- 协作设计见 ../design/shared-project-collaboration.md。本版没有启用邀请/个人分支/真实 Gitea PR。

验证：独立 Linux 容器重装三处依赖；后端/runner 1885 pass、4 skip；前端 1046 pass / 63 files；vue-tsc 与生产构建 rc=0。旧号池列表 UI 的断言替换为真实监听、刷新错误、过期淘汰、搜索与截断断言，原号池 API 与纯函数仍有覆盖。

另以 PostgreSQL TEMP 表验证新 SQL，覆盖 fresh/stale、池内/池外、移除/吊销容器、删除/停用用户，不写生产业务表。本地浏览器使用明确的模拟数据覆盖桌面/390px 手机、拖入上传、项目下发、删除确认、Esc 和端口搜索；不能把模拟数据视为真实协作上线证据。上线后再独立核对版本、API、页面和 SSO-only 入口。
