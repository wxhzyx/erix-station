# Station Console UI — 2026-11-03

本次按用户明确要求重新组织界面与设置权限，使用统一的 Station Console 视觉系统。

## 信息架构

| 入口 | 内容 | 权限 |
|---|---|---|
| 聊天模式 `/chat` | 独立对话、附件与历史 | 登录用户 |
| 工作模式 `/` | 项目、会话、文件、预览与开发任务 | 原工位准入规则 |
| 个人设置 `/settings` | 账号信息、语言偏好 | 登录用户 |
| 用量与额度 `/settings?tab=usage` | 共享每日 Token 用量、升级申请及申请状态 | 本人 |
| 共享项目 `/admin/projects` | 项目成员、邀请和 PR 审核合并，保留管理台导航 | 管理员 |
| 我的项目 `/projects` | 个人参与的共享项目与邀请 | 登录用户 |
| 项目交付 `/admin/delivery` | 上传交付包、指定用户下发、查看结果 | 管理员 |
| 项目审批 `/admin/approvals` | 变更审查与合并 | 管理员 |
| 成员与工位 `/admin/users` | 成员权限及工位生命周期 | 管理员 |
| 额度与申请 `/admin/quotas` | 按人调整额度、批准或拒绝升级 | 管理员 |
| API 与模型 `/admin/llm` | 上游接入、凭据和模型目录 | 管理员 |
| 用户模型分配 `/admin/model-access` | 按用户独立配置聊天与开发模型 | 管理员 |
| 仓库接入、预览资源 | 原仓库与端口管理功能 | 管理员 |

主导航统一放在紧凑顶栏（桌面 56px、手机 48px），不再占用工作区左侧宽度；管理台使用独立的横向业务导航。
模式切换不再混入配置表单。个人页不提供 API、上游地址、密钥或模型分配表单。
旧 `/mode-settings` 书签转到个人设置；旧管理台路径继续可访问。

## 视觉规范

- 白色导航，正文 `#1c293d`，辅助文字 `#69778d`。
- 页面背景 `#f5f7fa`，内容表面 `#ffffff`，强调色 `#2864dc`。
- Segoe UI / 系统中文字体用于阅读，Consolas 用于数据和辅助标识；无需外网字体请求。
- 控件 6px 圆角、面板 8px 圆角；表单、表格、通知、选中态和焦点共用设计变量。
- 登录、聊天、开发、个人设置和管理台使用相同标识与色板。
- 尊重减少动画设置，保留键盘焦点、错误提示和移动端布局。

实现沿用 Vue 3、Tailwind 与 Element Plus。`StationShell` 承担统一主导航，
`console-theme.css` 统一组件外观，`style.css` 管理页面结构。消息渲染、文件预览、Agent 调用与会话持久化契约不变。

## 导航与信息密度

- 管理台“共享项目”和交付列表“管理协作”均进入 `/admin/projects`；选择项目只更新当前路径的 query，不能跳出管理台或叠加第二套顶栏。
- 主导航只放模式切换、项目协作与管理台。个人设置、额度申请入口和退出统一进入头像下拉菜单；退出继续调用统一 `auth.logout()` 清理会话与用户状态。
- 聊天和工作模式右上角显示今日已用 Token / 每日上限的百分比；悬停看已用、上限、调用预留和剩余，点击进入完整额度页。每 30 秒及窗口重新获得焦点时刷新；无有效数据显示“—”，账号切换清空旧值。
- 桌面已显示项目侧栏，不再放“导航”按钮；手机折叠侧栏后显示“项目与会话”。
- 删除常驻附件支持说明、宣传空态、重复配置说明及辅助英文眉题。保留字段名称、真实状态、错误和删除确认。

## 配置权限

这次用户要求取代旧的“本人自选 API / 模型”规则：

- 新增管理员专用 `GET /api/admin/users/:id/mode-settings` 和
  `PUT /api/admin/users/:id/mode-settings/:mode`。
- 普通成员调用旧个人模型写接口或新管理接口均返回 403，不能靠手工请求绕开界面。
- 管理员代配保留目标用户的个人虚拟 key、用量归属和模式隔离，审计操作者记录管理员。
- 个人只读配置接口继续返回脱敏 DTO，不返回上游凭据。
- 不修改现有绑定、登录方式、默认额度、项目或数据库结构。
